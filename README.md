# Proyecto Simulación del Álbum Mundial FIFA 2026

Bienvenido al repositorio del Proyecto Simulación del Álbum Mundial FIFA 2026, desarrollado para aplicar conceptos de probabilidad, estadística y simulación computacional al proceso de colección e intercambio de cromos.

## Componentes del Proyecto

### Código Fuente

Simulador desarrollado en Python que modela la compra de fundas, la obtención de cromos, los intercambios entre participantes y el cálculo de estadísticas.

### Informe Final

Documento que describe el problema, la metodología utilizada, los algoritmos implementados y el análisis de resultados.

### Presentación

Resumen visual de los objetivos, desarrollo y conclusiones del proyecto.

## Objetivo del Proyecto

Determinar el número promedio de fundas adicionales necesarias para completar el Álbum Mundial FIFA 2026 en poblaciones cerradas de distintos tamaños, analizando el efecto de los intercambios entre participantes.

## Metodología

* Cada participante compra inicialmente 140 fundas.
* Los cromos repetidos se almacenan para intercambio.
* Se realizan rondas de intercambio entre participantes.
* Se calculan probabilidades de completar el álbum y fundas adicionales requeridas.
* Se ejecutan múltiples simulaciones para poblaciones de 1 a 50 participantes.

## Resultados Analizados

* Probabilidad de completar el álbum.
* Número de cromos faltantes.
* Fundas adicionales necesarias.
* Costo promedio por participante.
* Impacto del número de participantes en la eficiencia de los intercambios.
